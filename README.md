# Sylqora AI

### Your go-to study companion.

Sylqora is an AI study tool I'm building to make studying a little easier.

The idea is pretty simple: instead of using AI just to get an answer, I want Sylqora to actually help you **understand what you're studying**.

## What is Sylqora?

Sylqora is basically a study companion that you can talk to when you're stuck on something.

You can ask it questions, get concepts explained, work through problems, or just ask about something you don't understand.

For example:

* "Explain momentum."
* "I don't understand logarithms."
* "Can you explain this question?"
* "Why is my answer wrong?"
* "Explain this in a simpler way."

You don't need to know any special commands. Just ask.

## Why did I make it?

I started building Sylqora because I wanted an AI tool that felt more focused on **studying** rather than just being another general chatbot.

There are already a lot of AI tools out there, so I don't want Sylqora to just be another one.

The goal is to make something that actually helps students learn.

## What can you do with it?

Right now, Sylqora is still a work in progress, but the main idea is:

* 🧠 Understand difficult concepts
* 💬 Ask questions naturally
* 📚 Get help with studying
* ✏️ Work through problems
* 🔄 Ask follow-up questions when something doesn't make sense

I'm still working on making the responses and the overall study experience better.

## What's next?

There are a lot of things I want to add to Sylqora eventually.

Some of them are:

* [ ] Quizzes
* [ ] Notes
* [ ] Flashcards
* [ ] Better revision tools
* [ ] Progress tracking
* [ ] Exam preparation
* [ ] Personalised study help

Obviously, this is going to take time, so I'm building it one thing at a time.
